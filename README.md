# POV Finance Channel System

Research and a production pipeline for a faceless "POV: You…" personal-finance story channel, based on the competitor **Ollie Finance** (@Olliee_Finance) and its source channels.

| File | What it is |
|---|---|
| [`01-competitor-analysis.md`](01-competitor-analysis.md) | Data report: outliers, where the titles come from, title formula, script anatomy, description/tags, thumbnail and editing style, opportunities |
| [`02-video-pipeline.md`](02-video-pipeline.md) | Reusable step-by-step pipeline with NexLev calls, LLM prompts, and checklists, from idea to upload |
| [`03-production-bible.md`](03-production-bible.md) | Full production spec: script templates and measured pacing, voiceover, visuals/images, subtitles, music/SFX, editing timeline, tools and costs |
| [`04-example-script.md`](04-example-script.md) | A complete example pack: title, full original script, scene-by-scene image prompts, voice and music direction, thumbnail, description and tags |

Start with the pipeline. Use the bible for how each layer is made, and the example to see what a finished pack looks like.
